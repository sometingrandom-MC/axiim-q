# Axiim Q — Modern Native Kotlin & Jetpack Compose App

A ground-up native Android application in Kotlin and Jetpack Compose for controlling and streaming to the **Axiim Q UHD** wireless WiSA surround sound amplifier over the local network, as the original app was only built for 32 bit and is no longer supported.

## Features
- Speaker Configuration
- Custom Per Speaker EQ
- Virtual Remote
- Power Controls
- Input Selection
- Upmixer Selection
- Night Mode
- Volume Leveling
- Audio Streaming to Device
- Audio/Video Streaming to Axiim Q (partially implemented)
- and more!
